# Changelog

## 1.2.0 (November 2026)

- Standard Version 1.2: once an API capability is implemented and accepted, its API documentation describes only the active contract, with no implementation status, delivery history, transient test results or outstanding-work commentary.
- Historical changes go to the changelog, evidence to `docs/operations/evidence/`, open decisions to the new decision register, and delivery progress to the delivery tracker.
- Decision register and operations evidence added to the documentation set, repository layout, ADR standard, review checklist and glossary.
- Skill updated to apply and review the rule.

- Standard consolidated to Version 1.1: infrastructure layout and Terraform rules, hyperlinking, proactive runbooks, environment guides, failure mode and environment guide templates.
- Skill packaged as a Claude Code plugin and as an uploadable skill zip.
